PART 4 — CONVERSATION MODE
==================================================

After a successful wake phrase + command:

Activate a conversation session.

Conversation window:

30 seconds from the most recent successful interaction.

During this window:

The user does NOT need to say "Hey VOXYN" again.

Example:

Hey VOXYN
→ Yes?

Turn on flashlight
→ Flashlight on.

Open YouTube
→ Opening YouTube.

Set volume to 80
→ Volume adjusted.

Every successful interaction refreshes the 30-second timer.

If another command arrives while the window is active:

Process it directly through the normal VOXYN engine.

Do NOT bypass intent classification, risk checks or action verification.

When the conversation window expires:

1. Stop command listening.
2. Speak:

"Standing by."

3. End/clear the conversation session.
4. Return to wake-word detection.

PART 5 — IMPORTANT SESSION LOGIC
==================================================

Do NOT implement the session logic in a way where adding a new turn automatically makes an expired conversation appear active.

The order must be logically correct.

For example:

Before processing a follow-up command, determine whether the existing session is still active.

After a successful command:

refresh the session timestamp.

Do not use:

addTurn()
→ isActive = true
→ immediately check isWithinWindow()

as the only mechanism for determining whether the previous session was still alive.

The state machine must explicitly distinguish:

IDLE
WAKE_DETECTED
LISTENING
PROCESSING
RESPONDING
CONVERSATION_ACTIVE
RETURNING_TO_WAKE

Avoid race conditions between these states.
